# Library Forms
The library forms are a collection of forms that are used for navigating a knowledge base.

We provide the following forms for library.
* Home Page - Contains the following elements.
  * New books / chapters / articles etc.
  * List of user's last 3 item's they viewed
  * A search interface that allows the user to enter search terms and filter by category / topics
* Search Results
* Add new article / book / chapter / page
* View article / book / chapter / page
* Edit article / book / chapter / page
